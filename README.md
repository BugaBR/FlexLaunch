# FlexLaunch

Projeto **FlexLaunch** – um launchpad moderno inspirado no SplicePad, desenvolvido com **Next.js 13**, **TypeScript**, **Tailwind CSS** e **Framer Motion**.

## Visão geral
- Layout responsivo, com barra de navegação, hero animado e cards de programas.
- UI sofisticada usando cores personalizadas (primary, secondary, accent) e animações suaves.
- Estrutura de código organizada em `src/app`, `src/components` e `src/data`.
- SEO otimizado via componente `Meta`.
- API simples de health‑check.

## Como rodar localmente
```bash
# Instalar dependências (já feitas)
npm install

# Iniciar modo de desenvolvimento
npm run dev
```
A aplicação estará disponível em `http://localhost:3000`.

## Deploy
O projeto pode ser facilmente publicado no **Vercel** (ou outro provedor compatível com Next.js). Basta conectar o repositório e seguir as instruções padrão.
